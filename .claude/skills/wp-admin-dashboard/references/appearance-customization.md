# Appearance & Customization

## Themes / Templates
- If the project supports multiple front-end templates: a gallery of theme cards
  (screenshot, name, "Activate"/"Live Preview"/"Customize"/"Delete"). If it's a single
  fixed front-end, drop this screen and fold its settings into "Customize" below.

## Live Customizer
- Side panel with collapsible sections: **Site Identity** (title, tagline, logo upload,
  site icon/favicon), **Colors** (accent/brand color pickers, light/dark default),
  **Typography** (heading/body font pickers), **Homepage Settings** (latest posts vs a
  static page, and which page), **Menus**, **Widgets** — each section edits state that
  live-updates an iframe preview of the real site before saving.
- Device preview toggle: Desktop / Tablet / Mobile widths inside the preview iframe.
- **Publish** (applies immediately), **Save Draft**, or **Schedule** the changes;
  a "Discard changes" exit confirms if there are unsaved edits.

## Menus
- Drag-and-drop nested menu builder: left panel lists addable items (Pages, Posts,
  Categories, Custom Link with URL+label), right panel is the menu tree — drag to reorder
  or nest (indent = submenu, max depth configurable).
- Menu **locations**: assign a built menu to a theme location (Primary, Footer, Mobile).
- Support multiple named menus, switch between them via a dropdown.

## Widget / Block areas
- Named widget zones (Sidebar, Footer Column 1–N) each holding an ordered, drag-and-drop
  list of widget blocks: Recent Posts, Categories List, Search, Custom HTML/Text,
  Recent Comments, Tag Cloud — add/remove/reorder without code, settings per widget
  instance (e.g. "number of posts to show").
